# CoopSync for Godot 4

Инструмент для совместной разработки в редакторе Godot 4 в реальном времени. Плагин позволяет нескольким разработчикам одновременно работать над одним проектом через локальную сеть или интернет: видеть перемещение камер друг друга, выделенные узлы и мгновенно передавать измененные ресурсы.

---

## Возможности

- **3D-аватары и курсоры**: отображение положения и поворота камеры каждого участника в реальном времени с плавной интерполяцией.
- **Подсветка выделения**: когда другой разработчик выбирает узел в дереве сцены, вокруг объекта в 3D появляется полупрозрачный габаритный контейнер с его именем и цветом.
- **Автоматическая синхронизация при сохранении**: при нажатии `Ctrl + S` измененная сцена или файл автоматически отправляются всем подключенным клиентам с автоматической перезагрузкой открытой сцены.
- **Полная синхронизация проекта**: возможность в один клик передать все ресурсы (`.tscn`, `.gd`, `.tres`, текстуры, шрифты) новому участнику.
- **Безопасность данных**: создание резервных копий (`.bak`) перед перезаписью входящих файлов.
- **Управление сессией**: защита комнат паролем, список участников, смена акцентного цвета аватара и возможность исключения (kick) для хоста.

---

## Системные требования

- **Godot Engine**: 4.0+ (совместимо с 4.1, 4.2, 4.3+)
- **Сеть**: открытый UDP-порт на стороне хоста (по умолчанию `7777`) либо использование виртуальных сетей (ZeroTier, Radmin VPN, Tailscale).

---

## Установка

1. Скачайте репозиторий (кнопка **Code -> Download ZIP**).
2. Скопируйте папку `addons/coop_sync` в директорию `res://addons/` вашего проекта Godot.
3. Откройте проект в Godot.
4. Перейдите в **Проект -> Настройки проекта -> Плагины** (Project -> Project Settings -> Plugins).
5. Включите плагин **CoopSync**.
6. В левом доке появится панель управления **CoopSync**.

---

## Использование

### Хост (Создание комнаты)
1. В панели CoopSync укажите ваш никнейм.
2. Задайте порт (по умолчанию `7777`) и, при необходимости, пароль комнаты.
3. Нажмите кнопку **Создать**.
4. Сообщите ваш IP и порт коллегам.

### Клиент (Подключение)
1. Укажите ваш никнейм.
2. Введите IP-адрес хоста и порт.
3. Введите пароль (если задан).
4. Нажмите **Войти**.
